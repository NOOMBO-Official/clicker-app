# Clicker App

A simple, responsive clicker game built with vanilla JavaScript, Tailwind CSS, and `localStorage` persistence.  
Tap the button to earn points, then spend those points on upgrades that increase your click power or generate points automatically.

## Features

- **Instant click feedback** with a smooth counter animation.
- **Upgrade system**:
  - **Click Power** – each purchase adds +1 point per manual click.
  - **Auto‑Clicker** – each purchase adds +1 point per second.
- **Progress persistence** using `localStorage` (state survives page reloads).
- **Responsive UI** built with Tailwind CSS.
- No external build tools – just open `index.html` in a browser.
